## L02 双根矩阵

### 只读与 Git

同一 thread `019fa227-96fa-7182-afae-6db31f3f6889` 交替执行本地与远端读取、目录树、
字面搜索和 Git 状态，最终返回 `L02_READ_MATRIX_0331_OK`：

- 本地读取、树、搜索分别为 3、2、2 ms；本地 Git 为 6 ms 且仓库干净。
- 远端读取、树、搜索分别为 128、124、102 ms。
- 远端主根当前不是 Git 仓库，`workspace_git_status` 在 79 ms 后以
  `COMMAND_DENIED` 失败；审计仍记录 `target=remote`、`rootId=remote-primary`，
  没有回退本机或次级根。

### 双端写入

最初在 `on-request` thread `019fa227-96fa-7182-afae-6db31f3f6889` 中执行双端写入，
本地和远端的建目录、写入、读取均成功，但本地补丁审批被拒绝，turn 最终按预期报告
失败，清理审批也被拒绝。该失败样本没有隐去。

随后用保持连接的 `full-access` thread
`019fa255-6e5f-7ae3-9cc7-8570863fd33b` 先清理失败样本，再在两根间严格交替完成：

- 建目录、写入 `alpha\nbeta\n`、读取并核对两端相同 SHA-256；
- 按各自 `expectedHash` 精确补丁为 `alpha\nBETA\n`，再次核对相同新哈希；
- 重命名、读取确认正文与哈希不变，再按当前哈希删除文件和空目录；
- 最后本地 `workspace_git_status` 干净。

turn 完整耗时 103,968 ms，最终返回 `L02_DUAL_WRITE_0331_OK`。审计中本地补丁为
3 ms，远端补丁为 246 ms；所有成功操作保持各自 `local/secondary` 或
`remote/primary` 路由。
