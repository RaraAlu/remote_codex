## 根因、实现与恢复边界

- 官方 Webview 启动预取把 Remote SSH 根表示为 `\\root\\work\\train\\MimicLite`，Git worker
  的 `GitInitWatcher.startWatch()` 又直接调用本地 host 的 `fs.watch`，失败后以最多五秒
  间隔持续重连；该链路完全位于官方 UI Extension Host，Shim/App Server 无法拦截。
- 同一官方资产已经提供 working-tree watcher helper：它把活动 `vscode-remote` workspace
  folder 映射回真实 URI，并用 `vscode.workspace.createFileSystemWatcher` 监听。兼容层只把
  Git 初始化监视器的单个直接调用改接到这个现有 helper，不创建、替换或合成工作区 URI。
- 管理器先按代码形状确认上述三项能力，必须各自唯一；任何形状缺失或歧义均返回
  `unsupported`，不修改资产，也不阻断 Bridge 核心远程链路。
- 原始 `out/extension.js` 保存到 Bridge 状态目录，记录原始和补丁 SHA-256。写入使用同目录
  临时文件与原子替换；并发窗口通过锁协调。重复激活返回 `already-patched`，不会循环重载。
- 官方扩展升级只允许在同一扩展目录下迁移安全相邻的 `openai.chatgpt-*` 安装；外部资产
  修改、备份哈希变化、元数据路径篡改和未知安装根均拒绝覆盖。
- `Codex Bridge: Restore Official Codex Settings` 会在关闭自动初始化后恢复哈希匹配的原始
  资产。真实设置恢复未在本目标重复执行；精确恢复、已恢复、备份篡改、外部修改和路径
  篡改由 10 项兼容层自动化覆盖。

## 遗留风险与结论

- 兼容层修改当前用户安装的官方扩展入口资产，属于可恢复但非官方支持的适配方式；官方
  扩展升级若不再包含唯一匹配形状会失败关闭并保留 Bridge 核心能力，不会猜测新资产。
- 真实“恢复官方设置”命令、官方扩展真实升级后的迁移、完整 Windows M01-M11、Linux
  原生 stage/运行时和发布量化样本仍待后续总门禁执行。
- 最终结论：Windows x64 `git-init-watcher ENOENT` 消除及远端 Git/文件/命令无退化目标
  **限定范围通过**。本记录不构成 `0.4.0` 发布或完整双平台支持声明。
