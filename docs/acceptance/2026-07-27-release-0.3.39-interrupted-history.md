# Bridge `0.3.39` 中断工具跨轮历史验收记录

日期：2026-07-27

执行人：用户（`g1_1` Remote SSH 窗口重载）；Codex（注入运行中取消、跨轮历史读取、
审计、远端进程探针、自动化和产物复核）

复核人：待补测（官方 UI 视觉与取消矩阵、最终窗口关闭及 Windows x64）

## 目标

`0.3.38` 已在中断 turn 的即时完整读取中，把遗留的运行中远端工具投影为失败终态；
但 app-server 在开始下一 turn 后会从 `thread/turns/list(itemsView=full)` 省略上一
中断 turn 的工具项，外部 MCP 客户端再次读取时会丢失已确认的终态。

`0.3.39` 仅在同一外部会话客户端连接内，有界保留已经读取到的中断
`commandExecution.status=failed` 项。后续 turns page 省略该项时，按 thread、turn 和
item ID 恢复；已有同 ID 项不重复。缓存最多保留 64 个中断 turn、每个最多 32 个失败
命令项，不读取 Codex 会话文件、不恢复未完成状态，客户端重启后不延续。Remote
Executor 实现和协议未修改，继续使用 `0.2.19` / 11。
