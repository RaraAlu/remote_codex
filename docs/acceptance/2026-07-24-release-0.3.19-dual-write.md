## 变更与边界

| 项目 | 内容 |
| --- | --- |
| Bridge 版本 | `0.3.19` |
| 基线提交 | `b98d08b` |
| Remote Executor | `0.2.12`；诊断协议 7 |
| 新能力 | 双端整文件写入、精确补丁、目录创建、非覆盖重命名、文件或空目录删除 |
| 新握手能力 | `executeStdin`；按能力集合触发 Executor 更新，不按版本值门禁 |
| 声明范围 | Linux 本地自动化、Remote Executor 本地等价执行与 Linux 构包；真实窗口统一待补测 |

- 所有写工具都要求显式 `target` 与根 ID；远端仅允许唯一主根，本地仅允许已授权次级根。
- 整文件与补丁结果最多 1 MiB。覆盖、补丁、文件重命名和文件删除必须携带最近读取的
  SHA-256；过期哈希返回 `FILE_CONFLICT`。
- 整文件写入使用同目录临时文件、同步和原子替换；创建使用不覆盖的原子链接。目录只
  支持单级创建、非覆盖重命名和空目录删除，不开放递归删除。
- 默认 VS Code Remote 链路用 stdin 传正文，正文不进入 argv。远端复用 Executor
  结果账本，本地 Controller 使用独立有界账本。
- 覆盖、补丁、重命名和删除在需询问模式进入绑定调用 ID 的官方审批；创建文件和目录
  是有界自动操作；`full-access` 自动放行。审批和结果审计不记录正文。
