- Executor 新增 `workspaceStop` 能力和操作。运行时仍按能力集合而非版本号准入。
- 停止操作先在远端按规范工作区清理前台操作账本、后台任务和 stdio 会话，再关闭本地
  transport、会话文件和 socket。
- 远端停止无法确认时，`bridge.stop` 记录 `unknown` 并向调用方返回原错误，不把未知
  副作用伪装成成功。
- 设置恢复复用同一停止链，因此移除 Bridge 托管设置前也会清理远端工作区任务。

## 缺陷复现

在已安装的 `0.3.28` 上同时启动 1 个远端前台操作、1 个后台任务和 1 条 CodeGraph
stdio MCP 链路：

- 显式执行 `Codex Bridge: Stop` 前，远端前台、后台、MCP 和本地 relay 均为 1 条活动
  链路。
- 停止耗时 117 ms；前台返回 `CANCELLED`，MCP 与 relay 退出，会话文件被移除。
- 再次启动 Bridge 后，前台和 MCP 均为 0，但后台任务仍为 1，状态仍是 `running`。

该样本证明旧停止路径只关闭了前台 Executor 和 transport，没有向 Remote Executor
发送工作区级后台与 stdio 清理请求，因此判定失败。
