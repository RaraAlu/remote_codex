## 问题与修复链

- `0.3.40` 把线程响应中的内部档案投影为官方内置档案，但 `config/read` 仍公开
  `default_permissions=codex-remote-bridge`，其他模式无法稳定选择。
- `0.3.41` 隐藏配置默认值后，初始切换恢复；多次切换时
  `permissionProfile/list` 仍公开内部档案，选择器最终显示该内部 ID。
- `0.3.42` 只在确切的 `permissionProfile/list` 请求响应中过滤内部档案，并清理
  `config/read.origins` 的扁平权限来源键。线程内部仍固定使用本地拒绝档案和
  `approvalPolicy=never`，远端审批语义继续由原始客户端请求单独跟踪。
