# Bridge `0.3.38` 中断工具终态验收记录

日期：2026-07-27

执行人：用户（`g1_1` Remote SSH 窗口重载）；Codex（注入取消、历史读取、审计、

复核人：待补测（官方 UI 取消呈现、跨 turn 完整历史、最终窗口关闭及 Windows x64）

## 目标

精确 `0.3.37` 的外部 MCP 运行中取消已经使 turn 进入 `interrupted`，Bridge 审计也
记录 `CANCELLED`，远端进程树归零；但紧接取消读取该 turn 时，仍在运行的
`dynamicToolCall` 被投影为 `commandExecution.status=inProgress`，客户端可能继续
显示运行中状态。

`0.3.38` 只修复该已验证问题：当包含工具项的 turn 明确为 `interrupted`，且远端
动态工具项仍为 `inProgress` 时，Shim 将其投影为失败终态并给出中断说明。实时
`item/started` 以及非中断 turn 的投影不变。Remote Executor 实现和协议均未修改，
继续使用 `0.2.19` / 11。
