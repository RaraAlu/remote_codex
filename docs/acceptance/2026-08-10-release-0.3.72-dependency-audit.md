## 根因与修复

- 用户执行 `npm audit fix` 后仍看到 `fast-uri` 和上游 `ajv` 两个高危条目。两项实际来自
  同一依赖链；根 `package.json` 的 `overrides.fast-uri="3.1.4"` 是显式约束，npm 不能
  在普通审计修复中越过该约束。
- `GHSA-7p8r-x3mc-p8w7` 影响 `fast-uri >=3.0.0 <3.1.5`。覆盖值升级到 `3.1.5` 后，
  Ajv 继续使用兼容的 3.x API，同时不再命中该公告。
- 同一次 `npm audit fix` 还在既有版本范围内更新 `brace-expansion 5.0.9`、`hono 4.13.1`、
  `ip-address 10.5.0`、`js-yaml 4.3.1`、`nanoid 3.3.18`、`postcss 8.5.26` 和
  `undici 7.29.0`。未使用 `--force`，没有引入新的直接依赖或主版本降级。
