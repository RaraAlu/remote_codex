## 实现与安全边界

- 命令面板新增 `Codex Bridge: Authorize Local Root` 和
  `Codex Bridge: Revoke Local Root`。目录选择仅接受本地 `file` URI；授权前解析真实
  路径并拒绝文件系统根。
- 最多 15 个授权以 `local/secondary` 记录保存在扩展全局状态，并同步到 Bridge 配置
  和已有窗口会话配置。记录只包含根 ID、目标端、角色、路径和显示名，不包含密码、
  私钥、Token 或 Remote SSH 会话令牌。
- 本地执行器只实现读取、目录、目录树、字面文本搜索和固定参数的只读 Git 状态。
  文件、输出、目录项、树深、搜索字节和搜索项均有限额；不提供任意本地命令接口。
- 每次操作重新查询授权并解析授权根真实路径。父路径逃逸、目录内符号链接逃逸、授权
  根被符号链接重定向及撤销后的已有执行器请求均失败关闭。
- 现有动态工具仍只公开 `target="remote"`；本目标不声明 Codex 已能读取本地根。

## 遗留风险与结论

- 授权和执行器已经交付，但 Shim 双端路由尚未接入；当前公开工具不能请求本地目标。
- 候选 VSIX 的真实命令面板、目录选择、重载后持久化、诊断展示和撤销体验待补测。
- Linux Remote SSH 候选安装回归和 Windows x64 Extension Host 实机仍待补测。
- 最终结论：本地次级根已经具备明确授权生命周期和失败关闭的 Controller 只读执行
  基础；不据此声明完整双端读取能力。
