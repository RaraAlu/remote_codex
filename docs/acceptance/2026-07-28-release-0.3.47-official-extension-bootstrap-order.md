## 问题证据

- 复现环境为 VS Code `1.126.0`、Remote SSH `0.124.0`、
  `openai.chatgpt@26.5721.30844`、内置 Codex `0.146.0-alpha.3`，本机 Linux x64，
  远端 Linux ARM64。
- 官方扩展实际位于远端 Extension Host：
  `/home/unitree/.vscode-server/extensions/openai.chatgpt-26.5721.30844-linux-arm64/`。
- Bridge 首次自动初始化原先在写入
  `remote.extensionKind.openai.chatgpt=["ui"]` 前调用本地 UI Extension Host 的
  `vscode.extensions.getExtension("openai.chatgpt")`，因而误报扩展未安装。

## 修复

- 未托管 Shim 的合格 Remote SSH 窗口不再预先刷新官方 Codex 运行时，而是进入现有
  配置链路，安装 Shim、保存 Bridge 配置、设置 extension kind/CLI 入口并请求重载。
- 已有托管入口时先执行设置修复；设置变化会立即请求重载并终止本轮初始化，只有设置
  已生效时才读取官方扩展和内置 Codex。
- 没有根据官方扩展或 Codex 版本设置运行时门禁，仍以实际扩展加载与可执行能力为准。
