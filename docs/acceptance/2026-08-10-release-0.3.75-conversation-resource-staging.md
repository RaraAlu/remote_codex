## 范围

本记录覆盖 Linux x64 Controller 在真实 Remote SSH 窗口中的本机对话资源暂存、原生
`@` 输入和旧次级根数量上限移除。thread 声明后的本机只读访问、跨对话隔离、拒绝写入、
删除对话清理、禁用后的逐字节恢复以及 Windows x64 运行链路保持待补测。

## 实机结果

1. `0.3.75` 加载后，Bridge 于 `19:38:39` 从 `degraded` 到达 `ready`；输出确认官方
   Shim/app-server 已初始化，Remote Executor 包与运行时均为 `0.2.21`。
2. 用户从本机文件管理器一次拖入 14 个资源，其中 12 个目录、2 个文件。`20:14:24`
   和 `20:14:43` 两轮均记录 `source="system-file-manager"`、
   `insertionMode="inline-mention"`、`attached=14`、`failed=0`。
3. 审计在每轮为 14 项逐一写入 `conversation_resource.stage_drop`。同一组资源在旧实现
   `18:05:03` 会以 `The dropped local folders exceed the remaining local root authorization
   limit` 失败，因此本次结果直接证明拖放暂存不再受全局次级根数量限制。
4. 用户确认界面行为符合预期。当前日志没有出现 `conversation_resource.claim` 或
   `conversation_resource.delete_thread`，故本记录不把提交后的读取边界、跨对话隔离和
   删除清理标记为通过。
