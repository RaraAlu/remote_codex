## 实现与边界

- Bridge 自有动态工具逐项生成 selector：`workspace_*` 使用 `explicit-root`，省略根选择时
  落到 `remote-primary`；`remote_exec` 与后台工具固定使用远端主根。这些工具由 Shim
  实际提供，状态为 `available`。
- MCP 只按实际观察到的 server 路由生成 family selector。远端 executable 探针和
  app-server override 成功时状态为 `route-configured`，不宣称当前回合存在任何具体工具；
  只有出现在当前工具列表中的 provider tool 才能调用。
- App、Connector 与 Web 使用 `provider-managed`，执行位置保持 provider 定义；Bridge
  不授予这些家族远端工作区语义。
- 清单同时进入 thread 开发者指令、每轮
  `codex-remote-bridge-tool-routes` application context 和 `shim.start` 审计。模型被明确要求
  不得依据 `target` / `rootId` 参数是否存在推断执行位置。
- 清单不包含 executable、argv、cwd、env、进程环境、文件正文、凭据或 transport Token。
  本机 MCP 名称按现有审计脱敏规则记录，本文件不还原被脱敏名称。
