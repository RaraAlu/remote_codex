## 问题与修复边界

- `thread/list` 会返回状态为 `notLoaded` 的历史 thread，`thread/read` 和
  `thread/turns/list` 仍能读取其内容，但这两项读取不会把 thread 注册为可接受 turn 的
  运行对象。
- 修复前的真实调用顺序为 `thread/read -> turn/start`，官方 app-server 返回
  `thread not found`。
- 当前协议 Schema 明确提供 `thread/resume`，并说明按 `threadId` 从磁盘恢复 thread。
  修复后顺序为
  `thread/read -> thread/resume(excludeTurns=true) -> turn/start`。
- 该行为按实际能力和操作结果接纳，不根据官方扩展、Codex、Bridge 或协议版本值设置
  运行时门禁。
- 本目标只修改 Controller 包内 Shim 的外部对话客户端；Remote Executor 和远端执行
  协议不变。
