## 实现与自动化

- 工作区指纹包含 Bridge 版本、VS Code 版本、远端主机和规范根。
- 连接完成后若当前 Extension Host 代际没有受管 Shim，先持久化指纹，再自动重载一次。
- 相同指纹已经尝试时不再重载，只记录 detached 状态，避免故障循环。
- 定向测试覆盖首次缺失、已附着、同指纹和新根。
- 最终 `npm run check` 通过：82 个测试文件通过、1 个按预期跳过；431 项通过、8 项跳过；
  类型检查、构建、Shim 冒烟和 Linux x64 构包通过。
- 首轮完整测试有一个无关 `SharedAppServer` 审计完成时序断言短暂失败；单文件复跑 6/6
  通过，随后完整门禁零失败。
- `git diff --check` 通过。
