| 项目 | 内容 |

| Remote Executor | `0.2.11`；本次未修改 |
| 变更摘要 | 本地 Core 风险请求由已知方法枚举提升为命名空间失败关闭 |
| 声明范围 | 自动化和双平台构包；真实模型是否存在不经过外部请求/审批的专用工具路径待补测 |

- Remote SSH 配置生效时，`fs/`、`process/`、`command/exec`、
  `fuzzyFileSearch`、`thread/backgroundTerminals/` 和 `thread/shellCommand`
  请求全部由 Shim 拒绝。
- 当前协议中的 25 个已知方法继续作为兼容差异清单；未来同命名空间方法即使未知也被
  阻断，审计以 `knownMethod=false` 标识。
- 普通本地窗口没有 Bridge 远程配置，不启用该阻断。
- 本次没有声称修改 Codex Core 内部实现；真实模型诱饵负测统一留到最终候选。
