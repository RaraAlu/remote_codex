## 实机退出条件

1. 用户在当前本地窗口手动执行 `Codex Bridge: Enable Native Codex Drop Surface`，确认只
   出现一次新资产提示，VS Code 确认框关闭后 polkit 正常显示，成功后窗口自动重载。
2. Bridge 输出记录 Workbench 和 Webview 为 `patched` 或 `already-patched`，不再出现
   onboarding `conflict` 或 GNOME modal grab 导致的 `Request dismissed`。
3. 在普通本地窗口与用户手动连接的真实 Remote SSH 窗口中，分别从 Explorer 和系统文件
   管理器拖入文件、目录，确认当前光标只生成一个原生 `@` 且提交后的 turn 可读取。
4. 执行禁用，逐字节核对 Workbench、`product.json` 和官方 Webview 与本轮原始备份一致。

最终结论：`0.3.76` 已达到自动化和 Linux x64 候选构包阶段，但真实 VS Code/Remote SSH
集成仍待补测。依照项目推送门禁，本记录关闭前不得推送该集成修复。
